в maxflow_algo.html визуализация алгоритма поиска максимального потока Форда–Фалкерсона

описание алгорима:

Дан ориентированный взвешенный граф $G$ с неотрицательными весами, хотим найти максимальный поток из фиксированной вершины $S$ в фиксированную $T$.

Для этого мы создаем граф, который назовем остаточной сетью, который изначально равен графу $G$(если ребра нет, создаем его с весом $0$) и на каждой итерации находим в этой сети путь из $S$ в $T$, где все ребра $>0$ (кратчайший по кол-ву ребер), добавляем его к потоку, который строим и "вычитаем" его, т.е. из всех ребер на этом пути вычитаем минимальный из их весов, и прибавляем это же число к ребру в обратную сторону(когда мы добавляем путь к потоку, мы в каждом ребре делаем, чтобы либо оно либо обратное ему оставалось $0$, вычитая минимум). При таком определении остаточной сети нетрудно доказать, что мы получим максимальный поток тогда и только тогда, когда в ней не останется положительного пути из $S$ в $T$.

При этом ясно, что для чисел с общим делителем $d$(чаще всего, целые/рациональные) этот алгоритм закончится, т.к. на каждой итерации будет увеличивать поток хотя бы на $d$ работает за $O(FE)$, где $E$ и $F$ - количество ребер и размер максимального потока к $d$ соответственно. 

А вот для чисел без общего делителя, к сожалению этот алгоритм может работать бесконечно долго.
